# VoxelCraft — список версий (manifest v2)
#
# Формат:  версия|путь|ссылка|sha256
#   версия  — идентификатор, например 0.7
#   путь    — файл внутри папки versions\<версия>\, например voxelcraft.exe
#   ссылка  — прямая ссылка на файл (GitHub Releases)
#   sha256  — необязательная контрольная сумма (64 hex-символа)
#
# Путь на .zip — архив версии (игра + ассеты одним файлом). Лаунчер качает его
# и распаковывает в ту же папку, куда он скачался, поэтому в архиве пути уже
# без папки версии:  voxelcraft.exe,  assets/textures/grass.png
#   0.8|VoxelCraft-0.8.zip|https://...|sha256
#
# Строка со звёздочкой кладётся в корень лаунчера и общая для всех версий:
#   *|fonts/Monocraft.ttf|https://...|sha256
#
# Строка с «!» - сам лаунчер: по ней он сверяет свою контрольную сумму,
# скачивает новую, подменяет себя и перезапускается. Сумма обязательна.
#   !|launcher.exe|https://...|sha256
#
# Старый формат тоже понимается:
#   0.7|https://.../voxelcraft.exe
#
